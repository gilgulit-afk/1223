# אומנות העינוג הטנטרי — אתר סדנאות

אתר סטטי (HTML/CSS/JS ללא תלויות) בהשראת העיצוב המקורי מקנבה.

## מבנה
```
tantra/
├─ index.html      # כל תוכן האתר
├─ styles.css      # השפה העיצובית: פלטה, טיפוגרפיה, סקשנים, רספונסיביות
├─ script.js       # אנימציות כניסה, כפתור צף, טופס ההרשמה
└─ images/         # התמונות שנחתכו מהעיצוב המקורי
```

## מה צריך לעדכן
1. **פרטי קשר** — בראש `script.js`, באובייקט `CONTACT`:
   - `WHATSAPP` — מספר בפורמט בינלאומי ללא `+` וללא מקפים, למשל `972501234567`.
     אם ימולא, הטופס ייפתח כהודעת וואטסאפ מוכנה. אם יישאר ריק — ייפתח מייל.
   - `EMAIL` — כתובת המייל לקבלת הרשמות.
2. **תמונות** — הקבצים בתיקיית `images/` נחתכו מצילומי המסך של קנבה, ולכן ברזולוציה
   נמוכה יחסית. כדאי להחליף אותם בקבצי המקור באיכות מלאה (אותם שמות קבצים).

## פריסה
- **Vercel** — Framework Preset: `Other`, Root Directory: `tantra`, ללא build command.
- **Netlify / Cloudflare Pages** — Publish directory: `tantra`.
- כל שרת סטטי אחר: להעלות את תוכן התיקייה כמות שהוא.
