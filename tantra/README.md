# אומנות העינוג הטנטרי — אתר סדנאות

אתר סטטי (HTML/CSS/JS ללא תלויות) בהשראת העיצוב המקורי מקנבה.

## מבנה
```
tantra/
├─ index.html      # כל תוכן האתר
├─ styles.css      # השפה העיצובית: פלטה, טיפוגרפיה, סקשנים, רספונסיביות
├─ script.js       # אנימציות כניסה, כפתור צף, טופס ההרשמה
└─ images/         # התמונות שנחתכו מהעיצוב המקורי
```

## מה צריך לעדכן

### 1. הפעלת הטופס (חד-פעמי, חובה)
הטופס שולח את הפרטים ל-`gilgulit@gmail.com` דרך השירות FormSubmit,
שלא דורש שרת משלנו. **בפעם הראשונה שמישהו ישלח את הטופס** יגיע מייל
מ-FormSubmit לתיבה `gilgulit@gmail.com` עם קישור הפעלה — צריך ללחוץ עליו
פעם אחת. מאותו רגע כל הרשמה מגיעה ישירות למייל.

מומלץ לשלוח הרשמת בדיקה בעצמכן כדי להפעיל את זה מראש.

אם השליחה בשרת נחסמת (למשל בתצוגה מוגנת), הטופס נופל אוטומטית
לפתיחת הודעת מייל מוכנה לשליחה — כך שאף פנייה לא הולכת לאיבוד.

### 2. פרטי קשר
בראש `script.js`, באובייקט `CONTACT`:
- `WHATSAPP` — `972544799145` (054-4799145). כל כפתורי ההרשמה וכל כרטיס
  תאריך מפנים לשם.
- `EMAIL` / `FORM_ENDPOINT` — יעד הטופס.

### 3. תמונות
הקבצים ב-`images/` נחתכו מצילומי המסך של קנבה ולכן ברזולוציה נמוכה יחסית.
כדאי להחליף אותם בקבצי המקור באיכות מלאה (אותם שמות קבצים).
