# אומנות העינוג הטנטרי — אתר סדנאות

אתר סטטי (HTML/CSS/JS ללא תלויות) בהשראת העיצוב המקורי מקנבה.

## מבנה
```
tantra/
├─ index.html      # כל תוכן האתר
├─ styles.css      # השפה העיצובית: פלטה, טיפוגרפיה, סקשנים, רספונסיביות
├─ script.js       # אנימציות כניסה, כפתור צף, טופס ההרשמה
└─ images/         # התמונות שנחתכו מהעיצוב המקורי
```

## יצירת קשר — וואטסאפ בלבד
באתר אין טופס השארת פרטים. כל כפתורי "להרשמה" וכל כרטיס תאריך מקשרים
ישירות ל-WhatsApp במספר `972544799145` (054-4799145).

**שתי נקודות חשובות בבניית הקישורים** (ב-`index.html`):
1. הטקסט מקודד ב-URL encoding מלא, ולכן עברית, אימוג'ים ושורות חדשות
   מגיעים תקינים.
2. `text` **אינו הפרמטר האחרון** בקישור — אחריו בא `&app_absent=0`.
   זה מכוון: סיומת שמוצמדת לסוף הקישור בזמן הפתיחה (למשל
   `#no_universal_link`) נבלעת בערך של הפרמטר האחרון. כשהיא נבלעת
   ב-`app_absent` ההודעה נשארת נקייה. **אם מוסיפים קישור חדש — להשאיר
   פרמטר אחרי `text`.**

הודעת ברירת המחדל של כפתורי ההרשמה:
```
היי גילי 🌸
אני מתעניינים בסדנה הזוגית – מסע חקירה טנטרי ב־16.10.
נשמח לקבל פרטים ולשמור מקום לזוג שלנו 💗
```
כרטיסי התאריכים שולחים הודעה עם התאריך שנבחר.

## תמונות
הקבצים ב-`images/` נחתכו מצילומי המסך של קנבה ולכן ברזולוציה נמוכה יחסית.
כדאי להחליף אותם בקבצי המקור באיכות מלאה (אותם שמות קבצים).

## פריסה
- **Vercel** — Framework Preset: `Other`, Root Directory: `tantra`, ללא build command.
- **Netlify / Cloudflare Pages** — Publish directory: `tantra`.
- כל שרת סטטי אחר: להעלות את תוכן התיקייה כמות שהוא.
