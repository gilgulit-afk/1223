# תמונות האתר

הנח כאן את קבצי התמונות בשמות הבאים, והן יופיעו אוטומטית בעמוד:

- `woman.jpg`  — תמונת האישה (מופיעה בראש העמוד, מתחת לכותרת)
- `couple.jpg` — התמונה השנייה (מופיעה ליד פסקאות הטנטרה)

עד שקובץ קיים, מוצג במקומו מסגרת־ממלא־מקום מעוצבת.
כל עוד שומרים על אותם שמות קבצים — אין צורך בשינוי קוד.
